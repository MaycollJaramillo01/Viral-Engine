# MoneyPrinterTurbo 💸

### Generador de videos cortos con IA todo en uno

Indica un <b>tema</b> o una <b>palabra clave</b> para el video y MoneyPrinterTurbo generará el guion, buscará el material, creará los subtítulos y la música de fondo, y producirá un video corto en alta definición.

## Funciones 🎯

### Flujos de creación

- [x] Usa flujos con **AI Agent, WebUI, API o CLI** para crear rápidamente o producir de forma automatizada
- [x] Pasa de un tema a guion, voz, material, subtítulos, música y edición de forma automática, conservando el control de cada fase
- [x] Genera por lotes varias variantes de salida, revisa el historial de tareas e importa o exporta ajustes de generación y API keys

### Guiones y proveedores de modelos

- [x] Usa una suscripción de ChatGPT mediante [OpenAI - Codex](docs/codex-provider.md), con inicio de sesión por código de dispositivo y un selector de modelos dinámico
- [x] Elige explícitamente [OAuth nativo de ChatGPT](docs/chatgpt-provider.md) para la autorización oficial de la aplicación y los modelos de tu cuenta; se requieren una cuenta/espacio de trabajo apto y un navegador/entorno local
- [x] Genera o reescribe **guiones de video multilingües** con IA, o aporta un guion personalizado completo
- [x] Usa proveedores líderes como [Kimi / Moonshot AI](https://platform.kimi.ai?track_id=track-9e3b711aa2594e378f6fe5b8de718a76&aff=moneyprinterturbo), [OpenAI](https://platform.openai.com/api-keys), [Anthropic Claude](https://platform.claude.com/settings/keys), [Google Gemini](https://aistudio.google.com/app/apikey), [DeepSeek](https://platform.deepseek.com/api_keys), [Alibaba Cloud Qwen](https://qwen.ai/apiplatform), [Microsoft Azure OpenAI](https://portal.azure.com/#view/Microsoft_Azure_ProjectOxford/CognitiveServicesHub/~/OpenAI), [ByteDance VolcEngine Ark](https://console.volcengine.com/ark), [xAI Grok](https://console.x.ai/), [MiniMax](https://platform.minimax.io/) y [Xiaomi MiMo](https://platform.xiaomimimo.com/docs/zh-CN/quick-start/first-api-call)
- [x] Conéctate mediante [Shengsuan Cloud](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK), [APIMart](https://go.apimart.ai/gh-moneyprinterturbo), [Cloudflare AI Gateway](https://dash.cloudflare.com/), [Alibaba ModelScope](https://modelscope.cn/docs/model-service/API-Inference/intro), [AIHubMix](https://aihubmix.com/), [AIML API](https://aimlapi.com/app/keys), [EvoLink](https://evolink.ai/dashboard/keys), [OpenRouter](https://openrouter.ai/settings/keys), [API Route](https://www.api-route.com/), [Ollama](https://ollama.com/), [suscripción de Claude Code](https://code.claude.com/docs), [OneAPI](https://github.com/songquanpeng/one-api), [LiteLLM](https://docs.litellm.ai/docs/providers), [Groq](https://console.groq.com/keys), [Pollinations AI](https://enter.pollinations.ai/) y otros gateways compatibles o entornos locales

### Material de video e imagen

- [x] Sube tus propias **imágenes y videos locales**, u obtén material de stock en HD de [Pexels (gratis)](https://www.pexels.com/api/), [Pixabay (gratis)](https://pixabay.com/api/docs/) y [Coverr](https://coverr.co/developers?ctx=header_navigation)
- [x] Genera material de origen `768P` o `2K` con [Metaso MiniMax H3](https://metaso.cn/minimax-h3/?s=MPT), con clips de 4 a 15 segundos en `9:16`, `16:9` o `1:1`
- [x] Crea varios clips de video con IA con [Video con IA de Shengsuan Cloud](https://www.shengsuanyun.com/?from=CH_XUQ4OTSK) y combínalos con el flujo de voz, subtítulos y edición del proyecto
- [x] Usa la integración nativa de [Volcano Engine Ark Seedance](https://console.volcengine.com/ark/region:ark+cn-beijing/apikey) para generar imágenes coherentes a partir de segmentos individuales del guion
- [x] Convierte las palabras clave del guion en material de video original con [WaveSpeed AI](https://wavespeed.ai)
- [x] Accede a Seedance, Wan y otros modelos de texto a video mediante [OFox](https://ofox.ai) con una sola API key
- [x] Genera material de video con IA de 3 a 12 segundos mediante la API asíncrona de texto a video de [MuAPI](https://muapi.ai), con endpoint, proporción, resolución y sondeo configurables
- [x] Conecta servicios de [texto a imagen compatibles con OpenAI](https://platform.openai.com/docs/guides/image-generation) o gateways de imagen personalizados y convierte las imágenes generadas en clips de video animados
- [x] Ajusta la duración de los clips, el encuadre y el orden del material según las distintas proporciones y estilos narrativos

### Voz, subtítulos y música de fondo

- [x] Elige voz automática, audio subido o sin voz, con muestras de voz y vistas previas de la narración completa
- [x] Usa **Edge TTS (gratis, sin API key)**, Azure Speech, SiliconFlow, Google Gemini, Xiaomi MiMo, MiniMax, ElevenLabs, Chatterbox, Kokoro, Fish Audio, ModelBest VoxCPM y otros servicios de voz
- [x] Genera subtítulos y configura su fuente, posición, color, tamaño, contorno y estilo de fondo
- [x] Usa música de fondo aleatoria, local o generada con IA, con control de volumen independiente

### Salida y publicación

- [x] Exporta videos en vertical `9:16 (1080×1920)`, horizontal `16:9 (1920×1080)` o cuadrado `1:1 (1080×1080)`
- [x] Publica los videos terminados directamente en **TikTok, Instagram y YouTube Shorts**

## Requisitos del sistema 📦

- Plataformas recomendadas: Windows 10+, macOS 11+ o una distribución de Linux habitual
- El despliegue local requiere Python 3.11 o posterior; se recomienda Python 3.11
- No se necesita GPU, pero se recomienda si quieres una transcripción local más rápida, un procesado de video más rápido o una generación por lotes más fluida

| Elemento | Mínimo        | Recomendado    | Óptimo       |
| -------- | ------------- | -------------- | ------------ |
| CPU      | 4 núcleos     | 6 a 8 núcleos  | 8+ núcleos   |
| RAM      | 4 GB          | 8 GB           | 16+ GB       |
| GPU      | No necesaria  | 4+ GB de VRAM  | 8+ GB de VRAM |

- Si dependes sobre todo de LLMs en la nube, TTS en la nube y fuentes de material en línea, la CPU y la RAM importan más que la GPU
- Si usas `faster-whisper`, generación por lotes o un procesado local más pesado, una GPU mejorará notablemente el rendimiento

## Instalación y despliegue 📥

### Instalar el paquete oficial con pip

El paquete oficial en PyPI es **[mpt](https://pypi.org/project/mpt/)**,
mantenido por `harry0703`. El paquete `MoneyPrinterTurbo` de PyPI lo mantiene un tercero.

No hace falta clonar el repositorio. Requiere Python 3.11 o posterior; se recomienda Python 3.11.

**① Crea y activa un entorno virtual**

macOS / Linux:

```shell
python3 -m venv .venv
source .venv/bin/activate
```

Windows PowerShell:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

**② Instala e inicia**

```shell
python -m pip install mpt
mpt webui
```

La WebUI se abre automáticamente en el navegador. Usa `mpt webui --port 8503 --headless`
para elegir un puerto sin abrir el navegador. Para generar videos por CLI, consulta `mpt cli --help`.

**③ Configura los servicios y localiza tus archivos**

La aplicación crea `config.toml` en el primer arranque. Añade las API keys necesarias
para modelos en línea, material o servicios de voz en los ajustes básicos de la WebUI.
La aplicación instalada guarda por defecto la configuración y los archivos generados aquí:

| Sistema | Directorio de datos                                                       |
| ------- | ------------------------------------------------------------------------- |
| macOS   | `~/Library/Application Support/MoneyPrinterTurbo`                         |
| Windows | `%LOCALAPPDATA%\MoneyPrinterTurbo`                                        |
| Linux   | `~/.local/share/MoneyPrinterTurbo`, o `$XDG_DATA_HOME/MoneyPrinterTurbo`  |

Define `MPT_HOME` antes de iniciar para elegir otro directorio. Los videos generados están en
`storage/tasks` dentro de ese directorio. Para actualizar, activa tu entorno virtual y
ejecuta `python -m pip install --upgrade mpt`.

### Despliegue manual 📦

#### ① Crea un entorno virtual de Python

Usa [uv](https://docs.astral.sh/uv/) para gestionar el entorno de Python y las dependencias. El proyecto admite Python 3.11 o posterior; el ejemplo de abajo usa Python 3.11.

```shell
git clone https://github.com/harry0703/MoneyPrinterTurbo.git
cd MoneyPrinterTurbo
uv python install 3.11
uv sync --frozen
```

Si aún no usas `uv`, puedes seguir usando `venv + pip`.

```shell
python3.11 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Notas:

- `pyproject.toml` es ahora el manifiesto principal de dependencias.
- `uv.lock` fija el entorno resuelto, así que se recomienda por defecto `uv sync --frozen`.
- `requirements.txt` se conserva solo para la instalación antigua basada en `pip`.

#### ② Inicia la WebUI 🌐

Ten en cuenta que debes ejecutar los siguientes comandos en el `directorio raíz` del proyecto MoneyPrinterTurbo

###### Windows

```powershell
.\webui.bat
```

También puedes ejecutar `webui.bat` en CMD.
`webui.bat` prefiere el `.venv` del proyecto o el Python incluido en el paquete portable. Si no encuentra un Python del proyecto pero `uv` está instalado, recurre automáticamente a `uv run streamlit`.
Para permitir que otros dispositivos de tu red local accedan a la WebUI, ejecuta `set MPT_WEBUI_HOST=0.0.0.0` antes de ejecutar `webui.bat`.

###### macOS o Linux

```shell
sh webui.sh
```

El script usa automáticamente el entorno virtual del proyecto o `uv` y elige un puerto local disponible. Para permitir el acceso desde otros dispositivos de tu red local, ejecuta:

```shell
MPT_WEBUI_HOST=0.0.0.0 sh webui.sh
```

Al iniciarse, el navegador se abrirá automáticamente

#### ③ Inicia el servicio de API 🚀

```shell
uv run python main.py
```

Si ya activaste el entorno virtual a mano, también puedes ejecutar:

```shell
python main.py
```

#### ④ Modo CLI puro (sin navegador) ⌨️

Si no puedes usar un navegador ni redirección de puertos, genera videos directamente desde la
línea de comandos. El comando de generación completo más sencillo es:

```shell
uv run python cli.py --video-subject "Cómo la IA está cambiando la vida cotidiana"
```

Las opciones de estilo de subtítulos y de voz se resuelven en este orden: **opción explícita de la CLI >
valor `[ui]` guardado en `config.toml` > valor por defecto incluido**. Otros ajustes de generación,
como la música de fondo, el número de videos o el número de párrafos, no se heredan de
la WebUI. Si la WebUI está configurada para usar audio subido, pasa `--custom-audio-file`
de forma explícita, ya que la ruta subida no se guarda.

Para la referencia completa de comandos, la descripción de los parámetros y las instrucciones de uso,
ejecuta:

```shell
uv run python cli.py --help
```

Para ejecutar varias tareas seguidas, pasa un manifiesto JSON array o JSONL en UTF-8. Las opciones de la CLI
actúan como valores por defecto, y cada objeto sobrescribe campos de `VideoParams`:

```json
[
  { "video_subject": "Cómo funcionan los paneles solares" },
  { "video_subject": "Cómo funcionan los aerogeneradores", "video_aspect": "16:9" }
]
```

```shell
uv run python cli.py --batch-file ./tasks.json --stop-at video
```

El manifiesto se resuelve desde el directorio de trabajo actual. Los valores relativos de
`custom_audio_file` y de `video_materials[].url` locales que contiene se resuelven
desde el directorio del manifiesto; las rutas de archivo indicadas como valores por defecto de la CLI mantienen su semántica
normal relativa al directorio de trabajo actual. Un manifiesto está limitado a 100 tareas y 1 MiB.
Todas las entradas se validan antes de empezar la primera tarea, las tareas continúan tras un
fallo individual en ejecución, y el comando imprime un resumen JSON al terminar.
El resumen contiene `total`, `succeeded`, `failed` y `tasks`; cada entrada de tarea tiene
`index`, `task_id`, `status`, `result`, `failed_stage` y `error`.

## Voz, subtítulos y música de fondo 🎙️

### Síntesis de voz

La velocidad de habla de ElevenLabs depende del modelo elegido. El `eleven_multilingual_v2` por defecto acepta de 0,7× a 1,2×; elige `eleven_v3` para el rango REST más amplio de 0,25× a 4,0×. MoneyPrinterTurbo avisa de las selecciones no admitidas antes de enviar una petición de generación y conserva la velocidad elegida sin recortarla. Las velocidades no predeterminadas en `eleven_v4`/`eleven_v4_turbo` no se admiten. Otros IDs de modelo usan un rango de validación conservador de 0,7× a 1,2×; esto no garantiza que todos los modelos admitan el ajuste de velocidad. Si el proveedor devuelve `invalid_voice_settings`, la generación se detiene sin reintentar y muestra su explicación. La [validación real de v2/v3 informada por el mantenedor](https://github.com/harry0703/MoneyPrinterTurbo/pull/1578#issuecomment-6040107858) prevalece sobre el rango más amplio descrito en la [referencia oficial de ajustes de voz](https://github.com/elevenlabs/skills/blob/main/text-to-speech/references/voice-settings.md).

**Azure TTS V1** en la WebUI funciona con **Edge TTS** y es gratuito, sin API key. MoneyPrinterTurbo también admite **Azure TTS V2**, **SiliconFlow TTS**, **Google Gemini TTS**, **Xiaomi MiMo TTS**, **MiniMax TTS**, **ElevenLabs TTS**, **Chatterbox TTS** autoalojado, **Kokoro TTS** autoalojado, **Fish Audio TTS**, [ModelBest VoxCPM TTS](https://platform.modelbest.cn/console/docs/api/audio) y un modo sin voz.

Elige un proveedor y una voz en la WebUI, y sigue las instrucciones en pantalla para las credenciales necesarias. Edge TTS no requiere API key; [Azure TTS V2](https://portal.azure.com/) y otros proveedores en la nube requieren credenciales de sus respectivas plataformas. Consulta las voces disponibles de Edge TTS en la [lista de voces](./docs/voice-list.txt).

ModelBest VoxCPM requiere una API key y un ID de modelo con la capacidad `speech_synthesis`. Su respuesta SSE transmite audio WAV, que MoneyPrinterTurbo convierte automáticamente al MP3 que usa el flujo de video. Además del texto a voz estándar, la WebUI puede clonar la identidad del hablante a partir de un audio de referencia opcional. La interpretación de alta fidelidad reutiliza por defecto ese clip con su transcripción exacta, o acepta un ejemplo de interpretación aparte, y envía `prompt_audio` más `prompt_text` para continuar su ritmo, emoción y pronunciación. La WebUI puede usar la configuración local de Whisper para crear un borrador editable de la transcripción. Las subidas están limitadas a 20 MiB y cada WAV convertido a 5 MiB. El material de referencia se limita a la sesión del navegador y la tarea actuales, y no se escribe en la configuración, los preajustes, el historial de tareas ni los logs.

### Generación de subtítulos

Hay dos modos de generación de subtítulos:

- **edge**: usa las marcas de tiempo del TTS, es rápido sin GPU y es el modo por defecto.
- **whisper**: usa la transcripción local de `faster-whisper` cuando se necesita una línea de tiempo de subtítulos más precisa. El modelo se descarga en el primer uso.

Define `subtitle_provider` en `config.toml` para cambiar de modo. Whisper usa por defecto el modelo `large-v3`, de unos 3 GB. Para usar el modelo `large-v3-turbo`, más pequeño y rápido, de unos 1,6 GB:

```toml
[app]
subtitle_provider = "whisper"

[whisper]
model_size = "large-v3-turbo"
```

> En el primer uso, Whisper descarga automáticamente el modelo de Hugging Face. Si la descarga automática falla, descarga `whisper-large-v3` a mano desde [Hugging Face](https://huggingface.co/Systran/faster-whisper-large-v3).

Tras extraer el modelo, coloca todo el directorio en `.\MoneyPrinterTurbo\models`. La ruta final debe ser `.\MoneyPrinterTurbo\models\whisper-large-v3`:

```
MoneyPrinterTurbo
  ├─models
  │   └─whisper-large-v3
  │          config.json
  │          model.bin
  │          preprocessor_config.json
  │          tokenizer.json
  │          vocabulary.json
```

## Preguntas frecuentes 🤔

<details>
<summary>RuntimeError: No ffmpeg exe could be found</summary>

Normalmente ffmpeg se descarga y detecta automáticamente.
Sin embargo, si tu entorno tiene problemas que impiden la descarga automática, puedes encontrarte con este error:

```
RuntimeError: No ffmpeg exe could be found.
Install ffmpeg on your system, or set the IMAGEIO_FFMPEG_EXE environment variable.
```

En ese caso, descarga FFmpeg de [gyan.dev](https://www.gyan.dev/ffmpeg/builds/), extráelo y define `ffmpeg_path` con
la ruta real de instalación.

```toml
[app]
# Defínelo según tu ruta real; ten en cuenta que en Windows el separador de rutas es \\
ffmpeg_path = "C:\\Users\\harry\\Downloads\\ffmpeg.exe"
```

</details>

<details>
<summary>OSError: [Errno 24] Too many open files</summary>

Este problema se debe al límite del sistema sobre el número de archivos abiertos. Puedes resolverlo modificando el límite de archivos abiertos del sistema.

Consulta el límite actual:

```shell
ulimit -n
```

Si es demasiado bajo, puedes aumentarlo, por ejemplo:

```shell
ulimit -n 10240
```

</details>

Usa [proyectos locales con control de revisiones](docs/video-projects.md) para sustituir el material de escenas preparado, comparar revisiones y reconstruir solo las fases afectadas. La CLI opcional conserva los artefactos verificados y la última exportación correcta; no hace llamadas a proveedores ni publicaciones automáticas.
